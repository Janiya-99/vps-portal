7 Standard Operating Procedure (SOP): Project Deployment

Step 1: Provision Isolated Database & User

Never connect apps with MySQL root. Provision an isolated schema and user:

# Local Helper Script
./scripts/provision-db.sh <project-slug>

# Remote Non-Interactive Execution
ssh vps-prod 'bash -s' << 'ENDSSH'
source /opt/infra/database/.env
APP_DB="db_<project-slug>"
APP_USER="user_<project-slug>"
APP_PASS=$(openssl rand -base64 18 | tr -dc 'a-zA-Z0-9' | head -c 16)

docker exec -i shared-mysql mysql -u root -p"$MYSQL_ROOT_PASSWORD" <<SQL
CREATE DATABASE IF NOT EXISTS \`${APP_DB}\` CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER IF NOT EXISTS '${APP_USER}'@'%' IDENTIFIED BY '${APP_PASS}';
GRANT ALL PRIVILEGES ON \`${APP_DB}\`.* TO '${APP_USER}'@'%';
FLUSH PRIVILEGES;
SQL

echo "DB_HOST=shared-mysql"
echo "DB_PORT=3306"
echo "DB_DATABASE=${APP_DB}"
echo "DB_USERNAME=${APP_USER}"
echo "DB_PASSWORD=${APP_PASS}"
ENDSSH

Step 2: Configure Application Container (docker-compose.yml)

Place in /opt/apps/<project-slug>/docker-compose.yml without public host port mappings:

services:
  app:
    build:
      context: ./app
      dockerfile: Dockerfile
    container_name: app-<project-slug>
    restart: unless-stopped
    env_file: .env.production
    networks:
      - shared-network
    # IMPORTANT: DO NOT expose host ports (e.g. no "3000:3000" or "80:80")

networks:
  shared-network:
    external: true

Step 3: Route Inbound Traffic via Nginx Proxy Manager

  1. Log in to NPM Console at http://172.255.210.203:81.
  2. Navigate to Hosts → Proxy Hosts → Add Proxy Host.
  3. Set Domain Names: e.g. api.yourdomain.com or app.yourdomain.com.
  4. Set Forward Hostname / IP: app-<project-slug> (resolved automatically via Docker DNS).
  5. Set Forward Port: 3000 (Node/Next.js) or 80 (Nginx/SPA).
  6. Under SSL Tab: Select Request a new SSL Certificate, enable Force SSL and Block Common Exploits.
